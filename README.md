> *"What if your physiotherapist never left the room?"*

An end-to-end AI rehabilitation system for ACL recovery, combining real-time biomechanical sensing with conversational AI.

**Stack:**
```
Frontend  → Unity Android (AR Skeleton Tracking + Pose Overlay)
Backend   → FastAPI (Python) on Azure
STT       → Groq Whisper
LLM       → LLaMA 3.1 via Groq
RAG       → FAISS + clinical knowledge base
TTS       → Sarvam AI
```

**What makes it novel:**

- 🎙️ Voice-driven LLM dialogue mid-exercise  
- 📚 RAG-grounded clinical responses (no hallucinated therapy advice)
- 📄 2x IEEE conference papers submitted — AI Fusion Conference
